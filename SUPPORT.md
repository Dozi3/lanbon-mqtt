# Support

Use this repository's [issue tracker](https://github.com/Dozi3/lanbon-mqtt/issues)
for Lanbon MQTT bugs, setup questions and compatibility requests. This is a
community project with no guaranteed response time. Issues with this custom
integration belong here rather than in Home Assistant or HACS core trackers.

Before opening an issue:

1. Read [setup](SETUP.md) and [troubleshooting](docs/troubleshooting.md).
2. Check existing issues and the release notes for your version.
3. Record Home Assistant, HACS and Lanbon MQTT versions, reported type/firmware,
   Control status, a clear reproduction and expected/observed behavior.
4. Download diagnostics from the Lanbon integration menu and inspect them
   before attaching. Include only relevant sanitized logs/screenshots.

Do not share tokens, broker passwords, private keys, backups, `.storage` files,
public hostnames, real MACs/addresses or unfiltered MQTT captures. Replace
identities consistently in any minimal example. See [DIAGNOSTICS.md](DIAGNOSTICS.md).

Report vulnerabilities privately through [SECURITY.md](SECURITY.md). For
contributing code or documentation, see [CONTRIBUTING.md](CONTRIBUTING.md).
