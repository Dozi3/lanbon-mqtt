# Screenshot sources

The setup guide links these screenshots in order:

1. `01-hacs-custom-repository.png`: unchanged official HACS documentation image;
   see [third-party notices](../../THIRD-PARTY-NOTICES.md).
2. `02-setup-discovery.jpg`: native Lanbon discovery form.
3. `03-setup-options.jpg`: native setup options, including additional controls.
4. `04-root-settings.jpg`: an optional root form with illustrative values.
   The draft was discarded; it did not contact the example address.
5. `05-device-controls.jpg`: a synthetic two-gang device, its controls and status.
6. `06-dimmer.jpg`: the native brightness slider for a synthetic dimmer.

Images 2-6 were captured from Home Assistant Core 2026.10.1 with Lanbon MQTT
0.3.0-rc.4 in an isolated VM. Peer identities and MQTT data were synthetic.
The optional root values are examples to replace, not settings to copy.
Unavailable diagnostics indicate fields not reported by the demonstration.
The UI images have no browser address bar, credentials or household data.
No device-control UI was fabricated or altered for these screenshots.
